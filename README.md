# GemScan AI

Android application project for on-device visual scanning of surface rocks and highlighting **visually unusual candidates for further inspection**.

> Status: planning / early development. No installable APK or validated gemstone recognition model is available yet.

## Intended MVP
- Live Android camera preview (CameraX)
- On-device candidate rock detection (model to be trained and validated)
- Visual overlays and optional photo capture
- Offline operation where feasible
- Optimized for Redmi Note 11 (performance to be measured)

**Scientific limitation:** A phone RGB camera cannot reliably establish gemstone identity, authenticity, mineral composition, or market value. Visual flags are not gemstone identifications.
